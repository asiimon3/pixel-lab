# Pixel Lab · Fundamentos de IA aplicada

Aplicación web con viñetas animadas en pixel art, ejemplos, preguntas de reflexión y tests para la asignatura **Fundamentos de IA aplicada** (28 h) del Máster en Inteligencia Artificial, Cámara de Comercio de Granada y NTT DATA.

**Ver la aplicación:** https://asiimon3.github.io/pixel-lab/

## Contenido
- 5 bloques, 37 conceptos y 133 viñetas animadas paso a paso.
- Explicación, ejemplos, errores frecuentes y vocabulario por concepto.
- 238 preguntas: reflexión con respuesta orientativa y tests de autoevaluación.
- Glosario, repaso por bloque y progreso guardado en el navegador.

## Uso
- Clase: `F` pantalla completa, `→` / `←` paso siguiente o anterior, `Espacio` reproducir, `1`–`9` ir a una viñeta, `Mayús`+`→` siguiente concepto.
- Estudio: reproducción automática con tres ritmos, modo oscuro y vista en móvil.

## Ejecutar en local
No necesita servidor ni instalación: abre `index.html` en el navegador.

## Estructura
```
index.html          página principal
css/styles.css      estilos
js/engine.js        motor de dibujo pixel art
js/kit.js           piezas visuales reutilizables
js/app.js           rutas, visor, preguntas y progreso
js/content/b1-b5.js contenido de cada bloque
```
Para editar textos, preguntas o tests, modifica `js/content/b1.js` … `b5.js`.
